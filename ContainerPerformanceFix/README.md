# Container Performance Fix

EA 23.346 Nightlyの公式アップデートで★収納箱などのソート時に関するパフォーマンスの改善が行われました。
そのため現在は本Modを利用する必要はありません。

コンテナにおけるソートやページ切り替えのパフォーマンスを改善します。  
これにより、アイテムを大量に入れた★収納箱で発生する動作のもっさり感が軽減されます。
