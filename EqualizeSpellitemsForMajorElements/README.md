# Equalize Spellitems for Major Elements

魔法系アイテム (魔法書、魔法杖、巻物) の魔法について、属性ごとに設定されている魔法の制限を無くします。  
例えば炎の矢の魔法書、毒の光線の杖といったアイテムは存在しませんが、このModを導入すると生成されるようになります。ただし専門領域で選べない属性 (衝撃、無) は対象外です。

## このModがすること
* 魔法系アイテムにおける属性ごとの魔法の制限撤廃
  (混沌の剣の魔法書、酸の具象の杖、轟音の唄の巻物 といったものが増えます)

## このModがしないこと
* Modオリジナル魔法の追加
* 魔法系アイテムにおける魔法の種類を増やすこと
  (矢の杖、球の巻物 といったものは増えません)

Modの導入や利用停止はいつでも可能です。ただし本来魔法書が存在しない魔法をPCが覚えた場合、Modを無効化しても覚えたままになります。
