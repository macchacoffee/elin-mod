# More Effective Luck

能力の一つ「運」が戦闘以外の要素にも適用されるようにします。
また運を一時的に増減させる手段を少しだけ追加します (しないかもしれません) 

## 運の効力
* ランダムに数量や値が決まる要素が上振れやすくなります。
  * ランダムエンチャントの強化値
  * 依頼報酬でもらえるプラチナ硬貨の量
* ちなみに不幸な場合、上記の結果は悪い方に傾きやすくなります。

## 運を増減させる手段
* めでたい (かもしれない) 食べ物を食べると一時的に少し運が良くなります。
* 「災い」を覚えているパーティメンバーとの会話では「不幸になりたい」の選択肢が増えます。お願いすると不幸を求める変態PCのために災いをかけてくれます。
