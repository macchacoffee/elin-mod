# More Effective Luck

能力の一つ「運」が戦闘以外の要素にも適用されるようにします。
また運を一時的に増減させる手段を少しだけ追加します (しないかもしれません) 

## 運の効力
* ランダム決まる要素の結果が上振れやすくなります。
  * 生成される装備の品質
  * ランダムエンチャントの強化値
  * 依頼報酬でもらえるプラチナ硬貨の量
* ちなみに不幸な場合、上記の結果は悪い方に傾きやすくなります。

## 運を増減させる手段 (バフやデバフ)
* めでたい (かもしれない) 食べ物を食べると少し運が良くなります。
* 祝福された食べ物を食べた時、運が良ければたまに運が良くなります。
* 拠点に幸運の月が訪れるとPCの運がとても良くなります。
* 「災い」を覚えているパーティメンバーとの会話では「不幸になりたい」の選択肢が増えます。お願いすると不幸を求める変態PCのために災いをかけてくれます。
