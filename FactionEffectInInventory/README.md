# Faction Effect in Inventory

神々のアーティファクトが有するファクションエンチャントの発動条件に「インベントリに存在する時」を追加します。装備する必要はありません。  
ただし以下の場合は対象外です。
* 「それは装備するたびに呪われる」のエンチャントが付いている。
* PCの勢力 (ファクション) に属さないキャラクターのインベントリに存在している。

「諸々の理由で装備はできない…でも神様からのご褒美は常に身に付けていたい！」といったロールプレイ用途を主に想定しています。  

実装の関係上、コンソールやModなどの通常以外の手段でPCの信仰対象を変えた場合はファクションエンチャントの適用状態が一時的におかしくなる場合があります。その時はセーブしてロードしなおせば正しい状態に戻るはずです。
